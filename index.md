## Live notebooks

The NumPy and pandas notebooks on this site execute on deploy, and their code cells are
editable in place — press the run button on any cell and a Python kernel starts inside
your browser. No install, no server, no account. Change a parameter and see what it does
to the chart. (The deep-learning notebooks need PyTorch and a GPU, so they show the
outputs of their last local run.)
